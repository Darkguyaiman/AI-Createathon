# Product

## Register

product

## Users

AI Createathon organizers and administrators use this app during event preparation and live event operations. They need to register teams, publish timeline updates, control voting, record judge scores, and monitor standings quickly.

## Product Purpose

The product is the control panel and public event site for AI Createathon 2026. Success means organizers can run the event without confusion while the public pages keep a bold, high-energy event identity.

## Brand Personality

Bold, energetic, practical. The interface should feel like a live build room: direct, high-contrast, and action-oriented.

## Anti-references

Avoid generic dark SaaS dashboards, low-contrast gray interfaces, marketing-style admin pages, top-navigation admin shells, and unnecessary footers inside task screens.

## Design Principles

Use the public site's event identity inside the admin area without making workflows harder to scan.
Keep primary actions obvious and consistent across screens.
Prefer sidebar navigation for persistent admin context.
Use strong contrast, compact panels, and clear table/form hierarchy for fast event operations.
Keep decorative motion minimal inside admin pages.

## Accessibility & Inclusion

Use readable contrast for text, controls, and status labels. Preserve keyboard-visible focus states and avoid relying on color alone for destructive or status actions.
